Muse Windows — 可运行的桌面重建版本 0.3.0

开始使用
1. 打开 release\Muse-Windows-0.3.0-win32-x64\Muse.exe。
   或把同目录 ZIP 完整解压后，双击其中的 Muse.exe。请保留整个文件夹。
2. 打开左下角“设置”，填写自己的模型 API 地址、模型名称和 API Key。
   支持 OpenAI 兼容的 /chat/completions 服务；本地无密钥服务可留空 Key。
   地址可以是服务根地址、/v1 前缀，或完整 /chat/completions 地址。
3. “保存并测试连接”只查询模型列表；服务不支持 /models 时可手动填模型后实际发送消息。
4. 新建对话，或创建工作区并添加参考资料，然后发送问题。

已实现
- 真实流式模型回复、停止、重试、Markdown、代码与表格、复制。
- 会话保存、搜索、重命名、置顶、移动到工作区和删除。
- 工作区名称、描述、颜色、资料和关联对话。
- 文件选择/拖放、本地副本、文本预览；文本、Markdown、代码、CSV/JSON、DOCX及文字PDF提取。
- 工作区参考文档与显式附件参与模型上下文。
- 工作区内新建文本文件、多标签编辑、Markdown预览、Ctrl+S保存、冲突保护和关闭前提示。
- 输入框开启“文件助手”后，支持模型列出、读取、新建和保存资料，逐次确认写入并保留执行记录。
- 模型列表、连接检查、系统提示词、温度、浅色/深色/系统主题。
- Markdown/JSON对话导出、全部数据备份、安全合并导入。
- Windows本机密钥加密；API Key不会出现在界面快照或数据备份里。
- Ctrl+N新对话、Ctrl+K搜索、Enter发送、Shift+Enter换行。

数据与限制
- 对话、工作区、导入文件副本默认保存于当前Windows账户的应用数据目录。
- 原始文件不会因应用内移除而删除。程序不会执行附件中的脚本或命令。
- 发送消息时，会话和相关文档摘录会发送到你配置的模型服务。
- 每个文件上限25 MB，备份JSON上限150 MB；扫描版PDF不包含可提取文字时需要另做OCR。
- 模型上下文按每文件最多16,000字符、参考文档总计64,000字符、最近80条消息截取；截取内容有标记。
- API Key绑定当前Windows账户加密保存；换电脑时需重新填写。
- 文件助手需要模型支持工具调用；只读当前工作区和显式附件，写入前展示完整内容供确认。
- 停止和拒绝取消尚未执行的操作；已落盘的写入不会自动撤销，停止、重试和恢复后仍保留回执。
- 普通对话中本轮新建的文件，后续消息需显式附加或放进工作区才能继续操作。
- 此版没有接入原Muse的账户、VM、云服务、完整Space应用运行时、原版审批/自动化服务、实时语音或系统连接器。
- 原安装包的界面和协议已做静态逆向，但原产品全部语义与服务端源码未完整还原。
  此程序是按已恢复交互模型独立实现的Windows客户端，不宣称与原产品功能完全相同。

验证
- 134项后端/宿主检查通过，另有43项真实Electron桌面检查通过；模型服务仍使用本机模拟。
- 真实Electron桌面验收覆盖设置表单、工作区创建、聊天、文件上下文、重试/停止、DPAPI和PDF/DOCX。
- 桌面验收使用独立目录和本机确定性模拟服务；尚未使用你的真实API凭据做请求。
- 运行桌面验收后，截图和结构化结果保存在本地 test-results 目录，此目录不提交到仓库。

开发
  npm ci
  node node_modules/electron/install.js
  npm start
  npm test
  npm run test:desktop
  npm run package:win

从源码运行需要Node.js 24；自行打包后的Windows x64版本不需要Node.js。
重新打包不会覆盖已有release，修改版本号或移开旧版后再生成。
