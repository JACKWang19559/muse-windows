Muse Windows 0.21.0

独立、非官方的 Windows AI 工作台，使用你自己的兼容模型 API。
源码运行：安装 Node.js 24，按 README.md 安装依赖后执行 npm start。
便携包生成路径：release/Muse-Windows-0.21.0-win32-x64.zip。

支持聊天、文件与工作区、文件编辑、图片/音视频、PDF、Word 和 Excel 只读预览。
XLSX 支持多表、样式、合并格、部分公式和折线/柱形图；详细范围见 README.md。
完整逆向和全部功能重建仍未完成。原安装包、原账号及原服务不在本项目内。
首次打开设置填写服务地址、模型和可选 API Key。Windows 使用系统加密保存密钥。
不把个人配置、密钥或本地文件提交到仓库。
