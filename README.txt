Muse Windows 0.18.0

本版本便携包生成后的路径为 release/Muse-Windows-0.18.0-win32-x64.zip。
解压后保留整个目录，双击其中的 Muse.exe。
也可按 README.md 中的说明从源码运行。

首次打开“设置 → 模型连接”，填写自己的兼容模型 API、模型名及可选密钥。
提供聊天、文件与工作区、文件编辑、本地小应用、计划、知识与技能说明。
JSON / JSONL 支持结构树和源码切换；保存时检查整个文件是合法 JSON，错误时保留草稿。
多条记录的 JSONL 可以预览，但不能在此编辑入口直接保存。
CSV / TSV 支持表格与源码切换，第一行作表头，最多显示 1000 行数据。
表格只显示文字；编辑请切换源码，保存时不检查 CSV 格式。
小写 .tsv 按制表符解析，大写 .TSV 按逗号解析；实际输入编辑后换行统一为 LF。
文件预览下方可重命名，扩展名可修改；只重新提取预览，不转换原始字节。
有草稿时先保存、明确放弃或继续编辑；重名和过期请求会拒绝，失败保留输入。
工作台文件标识与引用保留，原始导入文件不变；中断后可同步恢复名称、位置和预览。
可下载文件或未保存的草稿副本；无效 JSON、多条 JSONL 也能下载，草稿和未保存提示保留。
没有修改时下载原格式文件，包括无法文字预览的二进制文件。单次副本最多 25 MiB。
图片和视频可全屏浏览或在文件工作台只读预览；工作区按资料顺序混合浏览，首尾停止。
聊天图片只在当前消息的图片附件内循环，聊天视频每次单独打开。
左右按钮、方向键或横向滑动切换，Esc 关闭；支持下载原始副本、确认移除与格式错误提示。
视频识别 MP4、WebM、MOV、M4V、AVI 和 MKV 后缀，不保证对应编码可播放；每个最多 25 MiB。
全屏视频初始静音、自动播放并循环，可暂停、静音和拖动进度；浏览器拦截时可手动播放。
文件工作台的视频不自动播放、不循环；错误可重试，也可下载不转码的原始副本，没有缩放或视频编辑。
从文件工作台进入全屏时停止侧栏播放，返回后从头待播。
实际媒体解码取决于内置浏览器；视频数据和图片像素不会自动交给文本模型，也不自动 OCR 或转写。
另支持已有聊天音频附件的本机播放，以及语音服务的声音试听。
MP4 和 WebM 优先进入视频预览；M4A 和 OGG 等音频继续使用音频播放器。
本地应用与聊天并排显示，普通消息可引用当前应用，排队与恢复保留原目标。
创建对话、首次提交和重试等待期间可停止；确认未发送的内容可恢复，已有新草稿时单独保留。
应用预览支持选择元素并发送修改说明；开启助手后，写入与构建仍逐次确认。
语音输入须在“设置 → 语音输入与声音”单独配置识别服务和模型；聊天连接不会自动用于听写。

本项目是独立、非官方的 Windows 重建，尚未覆盖原版全部功能。
0.18.0 已通过 707 项单元检查及 36 项视频专项桌面检查，使用自有合成视频和本机模拟服务。
0.17.0 的历史验收为 680 项单元测试、32 项图片专项及便携包的 367 项完整桌面检查。
这些检查不证明原版全部功能、所有视频编码或真实模型与扬声器已经验收。
下载专项仅模拟系统保存位置选择，未验收实际系统选择窗口。
