Muse Windows 0.8.1

解压 release/Muse-Windows-0.8.1-win32-x64.zip，保留整个目录，双击 Muse.exe。
也可按 README.md 中的说明从源码运行。

首次打开“设置 → 模型连接”，填写自己的兼容模型 API、模型名及可选密钥。
提供聊天、文件与工作区、文件编辑、本地小应用、计划、知识与技能说明。
语音输入须在“设置 → 语音输入”单独配置识别服务和模型；聊天连接不会自动用于听写。

本项目是独立、非官方的 Windows 重建，尚未覆盖原版全部功能。
完整使用方法、数据处理和限制见 README.md；原版恢复进度见 docs/reconstruction-status.md。
