# 重建进度

目标是继续分析原 Muse 8.0 客户端，并在 Windows 上恢复其功能。完整目标仍未完成；当前版本是可运行的独立客户端。

## 当前可运行部分

- 自有 Chat Completions 服务、流式聊天、停止和重试。
- 本地聊天、工作区、文件上下文、导出与备份恢复。
- 新建文本文件，多标签编辑、Markdown 预览、保存冲突保护及编辑中断恢复。
- 模型文件工具循环：列出、读取、新建、保存；逐次确认写入，保留执行回执，支持拒绝、停止和恢复。
- 回复引用与快照、用户消息删除占位、逐条消息搜索分页及精确定位、历史草稿召回和本次会话内的待发送队列。
- Windows 密钥加密、受限界面桥接与外部链接检查。
- 本地模拟服务的后端和真实 Electron 桌面验收，以及可选的真实模型验收工具。

## 原版证据与边界

静态分析已从原客户端枚举 125 个桥接动作、337 个声明路由和 76 个原生回调属性。这些是有界清单，既不是完整行为总数，也不是已完成实现的数量。原包包含的前端和 ARM64 原生部分已在 Windows 上分析；原 macOS 程序尚未执行，原服务端代码不包含在安装包中。

第二轮恢复了文件编辑的状态与保存流程、回复引用、搜索历史窗口、消息队列重试，以及 Space 和工具调用的部分协议。Swift 元数据进一步确认了本地动作规格、参数规格与基本参数类型。原界面中的“新建共享 Agent”存在已退役门控，不能将静态方法的存在当成实际可用功能。

0.3.0 根据已恢复的动作规格结构实现了独立的参数校验、能力声明和本地文件工具执行。接入自有模型服务的循环、权限名称、次数限制和逐次确认规则是本项目的实现选择，不能视作原版完整协议的复刻。原生调度、远程节点和原版权限规则仍在分析中。该版本通过 134 项后端/宿主检查及 43 项 Electron 桌面检查，使用本机模拟模型服务。

第四轮进一步恢复了引用参数、消息搜索和历史窗口、删除占位、输入框历史召回，以及三层内存发送暂存机制。原客户端的发送 FIFO 在取得服务端确认后释放，模型回复事件由另一条订阅链接收。尚未证实原版持久化可编辑发送队列或已发送聊天消息的原位编辑。Windows 适配器按对话串行完整模型生成，并明确区分未发送意图、已落本地消息和已发网络请求；初始化失败只回滚本次尚未分发的末尾消息，无法回滚时保留原消息身份供重试，避免重复追加。

0.4.0 通过 184 项后端/宿主检查和 78 项 Electron 桌面检查，覆盖引用、搜索分页与定位、删除清理、发送队列以及延迟确认期间的草稿保护。模型验证使用本机模拟，真实模型调用尚未验收。

原生定点分析还确认了 UI 调用 ID 与页面 generation 的双重匹配、通用调度的 HITL/权限顺序，以及原版整数参数类型编码。应用实际注册的外层 gate 另有放行型适配器，具体授权继续由内部路径研究，不能由通用分发器推断每个 OS 动作的授权行为。原生某个 UI broker 的 5 秒初始化值与 Web 声明的 6 秒不是统一超时行为的证明。

| --- | --- |
| 原生桥接 | 主消息分发器、Swift 异步路径与间接调用尚未全部解释 |
| Agent 与工具 | 已有四种本地文件工具及模型调用闭环；完整节点注册、传输、远程执行和原版生命周期仍未恢复 |
| 权限与审批 | 本地文件有逐次确认与范围校验；原版规则、其他能力权限及审批服务仍待恢复 |
| Space 应用 | 文件、构建、预览、选区上下文、发布与分享仍需独立运行时 |
| 聊天语义 | 已有本地引用、精确搜索、删除占位、草稿召回和内存队列；原版完整 canonical 历史/回合删除集合、跨会话线程、缓存恢复及服务端忙时处理仍未恢复 |
| 知识与技能 | 知识快照、能力描述、记忆和技能生命周期待实现 |
| 自动化 | 已恢复客户端调用线索，尚未实现调度与执行服务 |
| 语音、浏览器和电脑操作 | 尚未实现对应的 Windows 能力层 |
| 本地连接器 | 各应用权限、数据读取和索引需要逐项补齐 |
| 云端与协作 | 原账户、VM、远程 Agent、共享与同步服务不在安装包内；独立后端尚待实现 |
| 资源和验证 | 部分资源格式、原生运行时门控及与原版的动态对照仍未完成 |

原安装包、原资源、反编译片段和本地用户数据不包含在本源码仓库中。实现选择与原版观察分别记录，不能用当前测试通过推导为整个原产品已经还原。
