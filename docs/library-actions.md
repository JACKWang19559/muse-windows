# 固定、排序与多选删除

资料库的全部资源、文档和网页应用视图支持固定条目。固定后先显示固定项，再按所选日期、名称或大小排序其他条目。固定项初始使用本机的添加顺序，可在侧栏调整；取消后再次固定会排到已有固定项之后。媒体和全部文件视图保留各自排序，不提供这组应用目录操作。

展开侧栏后，“固定资料”列出当前个人空间或工作区的固定文件和应用，点击可打开对应预览或编辑器。拖动排序按钮，将条目放到另一固定项之前或之后；也可聚焦排序按钮，使用 ↑ / ↓ 上下移动、Home 移到开头、End 移到末尾。尚未提交的拖动可按 Escape 取消；切换空间或固定列表变化会结束该次拖动。

保存期间显示等待状态，收到成功回执后才更新顺序。后端核对条目与参照项所属空间，并比较操作开始时的完整固定列表；固定项、顺序或空间已经变化时会拒绝旧请求，刷新后再重试。排序只修改该空间的固定项，结果保存在本机。失败不会把未保存的位置当作已完成。

固定记录与当前文件或应用标识绑定，重启后保留，备份恢复会重映射标识。移除文件或应用会清理其固定记录；删除工作区时，仍保留的资料和固定项一起转到个人空间。它不会将文件正文、模型设置或聊天权限改为其他内容。

点击“选择”后可以逐项勾选、全选当前结果、清空或取消。切换空间或分类、进入或退出名称搜索、关闭资料库会清除选择；同一次搜索内改变关键词或切换排序会保留已选标识。删除按钮明确显示当前结果中可删除的数量。已选但被搜索隐藏的条目不会加入本次删除；确认窗口会列出本次具体名称。

取消确认会保留选择。确认后先退出选择，再分别执行每项删除；某项失败不会阻止其他项完成，也不会自动重试或恢复选择。文件及其未保存修改从工作台移除，电脑中的导入原件保留；应用的源码、构建和本地数据会删除。相关文件引用和固定记录会清理。删除无法撤销。

后端会再次核对条目标识、类型和所属空间。若记录已移除但磁盘副本清理失败，界面会区分“已删除并有清理警告”和“未删除”，并释放已删除文件的编辑器与附件引用；不会把这种情况误报为条目仍可用。

这是独立的本机适配。原版 All 是远端 artifact 目录，Windows All 汇总本机托管文件和应用；本机资料均由当前用户持有，没有原版共享收藏或远端能力目录。原版客户端已确认会发送“位于另一 artifact 之前或之后”的相对位置，系统导航另用数值顺序；服务端的默认分配、重排、持久化和权限规则仍未知。本机添加顺序、完整列表冲突检查和保存规则属于 Windows 实现。批量删除按托管记录标识执行，不模拟原版文件路径到远端目录的转换；确认不证明云端撤销、远端物理删除或完整跨 VM 行为。当前不提供批量下载或移动。
