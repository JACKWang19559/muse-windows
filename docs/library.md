# 本机资料库

侧栏的“资料库”集中浏览当前个人空间或工作区中的文档、图片、视频、音频、文件和本地网页应用。分类、名称搜索、日期/名称/大小排序都在本机完成；打开条目使用已有的文件预览、编辑器、媒体查看器和应用编辑器。打开资料库和切换分类会保留当前聊天与草稿。

“在聊天中创建”和“创建需求”只填入需求，不会发送消息、创建文件、启用工作区助手或批准工具。宽窗口填入当前聊天；窗口宽度小于 1024 时填入当前空间的新聊天草稿并返回聊天，原聊天草稿仍保留。附件、引用、知识配置和助手选择仍属于各自草稿，不随分类导航改变；已加入待发送列表的消息不被创建入口取消。

文档可先生成文字，需要保存为文件或生成网页应用时，可使用现有工作区助手并确认具体操作。当前没有图片、视频生成服务适配器，这两个入口用于填写创作需求；它们不保证生成媒体。应用编辑器中未保存的源码仍经过原有放弃修改确认。

这是对原版 Library 交互的独立本机实现。原版文档类型来自远端 artifact 记录，Windows 按托管文件名类型分类；“全部文件”指当前空间中已导入或创建的副本，并不扫描系统磁盘。名称搜索为字面匹配，不是文件全文搜索。日期按添加时间排序，不是文件最后打开时间。媒体分类识别扩展名，能否播放仍取决于实际文件与解码器。原版的 VM 文件系统、artifact 订阅、远端模糊搜索与云端发布仍未由本机资料库替代。本机固定和多选删除的范围见[详细说明](library-actions.md)。
